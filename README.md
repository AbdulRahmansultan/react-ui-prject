# React Job Cards

A simple job listing project built using React.js, HTML, and CSS.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Lucide React

## Features
- Job cards with company details
- Job title and location
- Salary and experience level
- Bookmark and Apply buttons

## Run Locally

```bash
npm install
npm run dev
```
